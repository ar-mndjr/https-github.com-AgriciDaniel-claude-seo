What is alt text?

Alt text is a short written description of an image, added in the alt attribute. Screen readers read it aloud, browsers show it if the image fails to load, and search engines and AI tools use it to understand what the image shows.

How to use the alt text generator

  1. Upload an image.
  2. Add a focus keyword and page context if you have them.
  3. Pick the suggestion that best describes the image.
  4. Paste it into the image's alt field in your CMS.

How to write good alt text

  • Describe what is actually shown, in one sentence.
  • Keep it under about 125 characters.
  • Use a keyword only when it fits naturally.
  • Skip "image of" since screen readers already announce images.
  • Use empty alt (alt="") for purely decorative images.

Alt Text Generator FAQs

Does alt text help SEO?

Yes. It helps images rank in Google Images and gives search engines context about the page.

Should every image have alt text?

Every meaningful image should. Decorative images should use an empty alt attribute.

Is AI-generated alt text accurate?

Usually, but always review it, especially for products, people and charts.
