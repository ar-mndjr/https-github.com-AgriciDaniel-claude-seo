What is an XML sitemap?

An XML sitemap is a file that lists the pages you want search engines to find and index. It matters most for new sites, large sites and pages with few internal links.

How to use the XML sitemap generator

  1. Paste your URLs or crawl your site.
  2. Choose whether to add lastmod dates and images.
  3. Generate and download sitemap.xml.
  4. Upload it to your site root and add it to robots.txt.
  5. Submit it in Google Search Console.

Sitemap best practices

  • Include only indexable, canonical pages.
  • Keep lastmod honest: update it only when content changes.
  • Split large sites into multiple sitemaps with an index file.
  • Most CMSs generate sitemaps automatically. Use this tool for static or custom sites.

XML Sitemap Generator FAQs

Does WordPress need a sitemap generator?

Usually not. WordPress and SEO plugins like Yoast create one automatically.

Do priority and changefreq matter?

Google ignores them, so this tool leaves them out.

How do I submit my sitemap?

In Google Search Console, open Sitemaps, paste the URL and submit.
