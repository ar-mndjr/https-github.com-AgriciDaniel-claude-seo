# SEOcampaign website

WordPress site for SEOcampaign: SEO services, web development and free SEO tools.

- **Theme:** `app/public/wp-content/themes/seocampaign/` handles presentation.
- **Plugin:** `app/public/wp-content/plugins/seocampaign-tools/` holds the interactive SEO tools.
- **Design:** `design/mockups/`. Open `index.html` in a browser.
- **Stack:** WordPress, PHP, HTML, CSS and vanilla JavaScript. No page builders, frameworks or paid plugins.

This repository's root is the [Local](https://localwp.com) site folder
(`C:\Users\<you>\Local Sites\seocampaign\`). Git tracks only the theme, plugin, design, docs and config.
WordPress core, `wp-config.php` and uploads stay out of Git.
